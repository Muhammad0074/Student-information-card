onclick vs addEventListener()

onclick

The onclick attribute is set directly in the HTML or JS. It only allows you to add one function to a click. If you add a second one, it overwrites the first one.

addEventListener()

The addEventListener() method is a modern way to listen for events in JavaScript. It lets you attach multiple functions to the same event on an element without overwriting them.

Why addEventListener() is preferred:

We prefer using addEventListener() in modern JavaScript because it keeps our HTML code clean from JavaScript code. It also prevents scripts from overwriting each other when they need to do something on the same click. Finally, it makes it easier to remove the listener later if we want to stop listening to events.
